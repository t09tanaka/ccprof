# ccprof Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, globally installable `ccprof` CLI that profiles Claude Code sessions per PR and emits evidence-backed recoverable-time findings.

**Architecture:** Normalize tolerant Claude JSONL into source-independent events, attribute wall-clock intervals, match work against the final git diff, run pure detectors, reconcile claimed intervals through one ledger, then store and report JSON v2. Filesystem, git/gh, and persistence stay behind narrow adapters so the core remains deterministic and fixture-testable.

**Tech Stack:** TypeScript ESM, Node.js built-ins, external `git`/optional `gh`, built-in `node:test`, npm global `bin`.
